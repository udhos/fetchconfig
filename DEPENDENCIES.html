Dependencies

fetchconfig

Two views are given: Perl core-vs-CPAN status per Perl release, and the distribution package to install on RHEL 9, SLES 15 and Ubuntu 24.04 LTS.

Perl releases used as reference points:

PerlPlatform
5.26SLES 15 SP7
5.28AIX 7.2 TL5
5.40current

"core" = ships with that Perl; "CPAN" = install separately. None of the CPAN modules below has ever been core, and none becomes core in 5.40 -- the network/web/SNMP transport libraries are CPAN in every release. Everything fetchconfig needs that is NOT a transport is core in all three releases, unchanged between 5.26 and 5.40.

fetchconfig loads a model's transport module only when that model is used (one "use" per model file), so a site installs only what its device types require. The base install (telnet models) needs exactly one CPAN module, Net::Telnet.

03

AIX 7.2

Two Perls exist on AIX, and the choice decides how modules install:

  • System Perl (perl.rte): the default /usr/bin/perl. On AIX 7.2 TL5 this is Perl 5.28 -- the interpreter fetchconfig uses out of the box.
  • AIX Toolbox Perl (dnf install perl): a separate, newer Perl (5.30+) under /opt/freeware, managed by dnf.

They do NOT share a module path: the Toolbox perl-* RPMs install into the Toolbox perl's @INC (/opt/freeware/lib/perl5/...), which perl.rte does not search. A Toolbox perl-Net-SSLeay is therefore invisible to /usr/bin/perl. Pick one interpreter and install all non-core modules for that one (and make fetchconfig's #! line point at it).

All "core" modules above ship with both Perls; only the non-core modules below need installing (same set as the Linux matrix):

XS modules must be compiled; pure-Perl modules install without a compiler. Net::SMTP (libnet) and Digest::SHA are core in both Perls, so the e-mail summary needs no extra module -- only TLS adds Net::SSLeay + IO::Socket::SSL.

Option A -- system Perl (/usr/bin/perl, perl.rte 5.28)

The Toolbox perl-* RPMs do not apply here; install every non-core module from CPAN against the system perl. XS modules need a C compiler (IBM XL C, or gcc from the AIX Toolbox) and, for Net::SSLeay, OpenSSL development headers (IBM openssl.base, or openssl-devel from the Toolbox).

# one-time: compiler + OpenSSL headers for the XS modules
dnf install gcc make openssl-devel           # Toolbox; or use IBM XL C

# telnet-only (minimum)
cpan install Net::Telnet
# + SSH models                                (IO::Tty provides IO::Pty, XS)
cpan install Net::OpenSSH IO::Tty
# + web-UI models (HTTPS)
cpan install LWP::UserAgent LWP::Protocol::https IO::Socket::SSL Net::SSLeay
# + procurve-snmp (SNMPv3 crypto as needed)
cpan install Net::SNMP Net::TFTP Digest::HMAC Crypt::DES Crypt::Rijndael
# + SMTP over TLS: IO::Socket::SSL + Net::SSLeay (as above)

Option B -- AIX Toolbox Perl (dnf perl, 5.30+)

Run fetchconfig with the Toolbox perl (point the #! line at /opt/freeware/bin/perl, or invoke it explicitly). The Toolbox can supply the TLS XS modules precompiled, so the hardest XS build (Net::SSLeay) needs no compiler; the transport modules still come from CPAN, built with gcc.

dnf install perl gcc make

# TLS stack precompiled from the Toolbox (avoids building Net::SSLeay)
dnf install perl-Net-SSLeay perl-IO-Socket-SSL
#   perl-libwww-perl / perl-LWP-Protocol-https too if your Toolbox has them,
#   otherwise add them via cpan below.

# telnet-only (minimum)
cpan install Net::Telnet
# + SSH models                                (IO::Tty is XS -> needs gcc)
cpan install Net::OpenSSH IO::Tty
# + web-UI models (HTTPS)
cpan install LWP::UserAgent LWP::Protocol::https
# + procurve-snmp (SNMPv3 crypto as needed)
cpan install Net::SNMP Net::TFTP Digest::HMAC Crypt::DES Crypt::Rijndael

Install commands (layered)

Prerequisites (run once):

# RHEL 9 / Rocky 9 / Alma 9 -- enable EPEL and CRB
dnf install -y epel-release
dnf config-manager --set-enabled crb        # Rocky/Alma: 'crb enable'

# SLES 15 -- register Package Hub (use 15.7 on SP7)
SUSEConnect -p PackageHub/15.6/x86_64

# Ubuntu 24.04 -- 'universe' is default; enable if missing
add-apt-repository universe && apt update

RHEL 9 / Rocky 9 / Alma 9:

# (a) telnet-only
dnf install perl perl-Net-Telnet
# (b) + SSH models
dnf install perl-Net-OpenSSH perl-IO-Tty
# (c) + web-UI models (HTTPS)
dnf install perl-libwww-perl perl-HTTP-Message perl-LWP-Protocol-https perl-IO-Socket-SSL perl-Net-SSLeay
# (d) + SNMP model (Net::TFTP from CPAN; SNMPv3 crypto as needed)
dnf install perl-Net-SNMP perl-Crypt-DES perl-Digest-HMAC perl-Crypt-Rijndael
cpan install Net::TFTP
# (e) + SMTP over TLS (Net::SMTP is core; add the TLS stack)
dnf install perl-IO-Socket-SSL perl-Net-SSLeay

SLES 15 SP6/SP7:

# (a) telnet-only
zypper install perl perl-Net-Telnet
# (b) + SSH models
zypper install perl-Net-OpenSSH perl-IO-Tty
# (c) + web-UI models (HTTPS) -- from the Basesystem Module
zypper install perl-libwww-perl perl-HTTP-Message perl-LWP-Protocol-https perl-IO-Socket-SSL perl-Net-SSLeay
# (d) + SNMP model (SNMPv3 crypto as needed)
zypper install perl-Net-SNMP perl-Net-TFTP perl-Crypt-DES perl-Digest-HMAC perl-Crypt-Rijndael
# (e) + SMTP over TLS
zypper install perl-IO-Socket-SSL perl-Net-SSLeay

Ubuntu 24.04:

# (a) telnet-only
apt install perl libnet-telnet-perl
# (b) + SSH models
apt install libnet-openssh-perl libio-pty-perl
# (c) + web-UI models (HTTPS)
apt install libwww-perl libhttp-message-perl liblwp-protocol-https-perl libio-socket-ssl-perl libnet-ssleay-perl
# (d) + SNMP model (SNMPv3 crypto as needed)
apt install libnet-snmp-perl libnet-tftp-perl libcrypt-des-perl libdigest-hmac-perl libcrypt-rijndael-perl
# (e) + SMTP over TLS
apt install libio-socket-ssl-perl libnet-ssleay-perl

Crypt::Rijndael is only needed for SNMPv3 AES privacy; drop it for DES-only or v1/v2c.
